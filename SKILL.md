# SKILL.md — Навыки и компетенции команды для проекта «Презентатор» (Presentation Generator)

## Цель документа
Зафиксировать набор технических и продуктовых навыков, необходимых для реализации проекта, а также текущий уровень компетенций команды. Документ используется для планирования задач, распределения ролей, оценки рисков и формирования плана развития навыков.

---

## 1. Базовые навыки (обязательные для всех разработчиков)

| Навык | Описание | Критерии подтверждения |

## 2. Ключевые навыки по модулям проекта

### 2.1. Backend (FastAPI + архитектура)

| Навык | Описание | Критерии |
|-------|----------|----------|
| FastAPI & Uvicorn | Роуты, зависимости, middleware, фоновые задачи, валидация (Pydantic), OpenAPI | Реализованные эндпоинты, автодокументация, обработка ошибок |
| Асинхронность и очереди | Redis, Celery/RQ/ARQ, паттерны task queue, retry, backoff | Рабочий воркер, очередь задач, статусы, повторные попытки |
| Проектирование API | RESTful принципы, версионирование, пагинация, фильтрация, rate limiting | Чёткие контракты API, согласованная структура ответов |
| Безопасность | API-ключи, JWT, CORS, валидация входных данных, защита от инъекций | Реализованная аутентификация, безопасные заголовки, валидация схем |
| Логирование и мониторинг | Structlog/logging, метрики, healthcheck, tracing (опционально) | Логи в структурированном формате, эндпоинт `/health`, базовые метрики |

### 2.2. Генерация презентаций (python-pptx)

| Навык | Описание | Критерии |
|-------|----------|----------|
| python-pptx API | Работа с презентациями, слайдами, масками, формами, текстом, таблицами, изображениями | Слайды с разными типами контента, корректное применение шаблонов |
| Применение шаблонов | Мастер-слайды, цветовые схемы, шрифты, колонтитулы, логотипы | Презентация сохраняет корпоративный стиль, нет «сброса» оформления |
| Автоматическое распределение контента | Разбиение текста на смысловые блоки, подбор типа слайда, контроль длины текста | Презентация из 10–15 слайдов формируется автоматически без ручной правки |
| Обработка кириллицы и спецсимволов | Кодировки, экранирование, автоподбор размера текста | Нет искажений текста, корректная вёрстка на русском языке |

### 2.3. LLM-модуль и AI Visual Advisor

| Навык | Описание | Критерии |
|-------|----------|----------|
| Интеграция LLM | Абстракция провайдера, промптинг, парсинг структурированных ответов (JSON) | Работает с разными провайдерами, стабильные ответы, валидация JSON |
| Промпт-инжиниринг | Системные промпты, few-shot примеры, контроль формата вывода | LLM стабильно возвращает нужную структуру, минимум ошибок формата |
| Логика рекомендаций (Visual Advisor) | Правила подбора визуализации (линейный график, круговая диаграмма и т. д.) | Рекомендации соответствуют типу данных, есть fallback-правила |
| Контроль качества LLM | Валидация схемы, повторные запросы, fallback на детерминированную логику | Система не ломается при нестабильном ответе LLM, есть механизмы восстановления |

### 2.4. Хранение и обработка файлов (MinIO/S3, PostgreSQL, Redis)

| Навык | Описание | Критерии |
|-------|----------|----------|
| Работа с PostgreSQL | SQL, миграции (Alembic), индексы, транзакции, нормализация | Схема БД, миграции, базовые запросы, индексы для поиска |
| S3‑совместимое хранилище | Загрузка/скачивание файлов, политики доступа, пре-подписанные URL | Файлы сохраняются и скачиваются, нет потерь, корректные права доступа |

| Конвертация PPTX → PDF | LibreOffice headless, обработка ошибок, таймауты | Конвертация проходит без потери контента, ошибки логируются |

## 4. Релевантные навыки с учётом твоего стека (ML, RAG, биометрия)

Учитывая твой опыт с ML‑системами, RAG и биометрией, в проекте «Презентатор» особенно полезны:

- **Работа с структурированными данными** — подготовка данных для слайдов (таблицы, диаграммы), валидация форматов.
- **Интеграция с внешними сервисами** — аналогично интеграции ML‑моделей и векторных баз в RAG‑системах.
- **Управление версиями и экспериментами** — как в ML‑экспериментах, здесь пригодятся версионирование шаблонов и истории генераций.
- **Обработка ошибок и отказоустойчивость** — аналогично пайплайнам дообучения и инференса ML‑моделей.
- **Производительность и масштабирование** — опыт работы с нагрузкой (в т. ч. >10 000 RPS) поможет при проектировании очередей и воркеров.
